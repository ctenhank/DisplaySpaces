# DisplaySpaces 1.0.0

The first release of DisplaySpaces brings independent workspaces to each
display on Windows 11, with an optional linked mode for switching all displays
together. DisplaySpaces is the new name for BetterVirtualDesktop.

## Highlights

- Create, rename, reorder, and remove desktops on each monitor.
- Open a task view overlay on every monitor with window previews and desktop cards.
- Drag windows between desktops and monitors, including onto a new desktop card.
- Switch to a window's desktop by selecting its taskbar icon or window preview.
  Multiple windows from the same application are handled individually.
- Customize keyboard shortcuts, including a preset using Windows desktop shortcuts.
- Choose independent or linked display switching, wraparound or bounded navigation,
  and whether to follow a window moved with a previous/next desktop shortcut.
- Show the current desktop name on demand or continuously, with first/last desktop
  indicators and a choice of top-left or top-right placement.
- Select English, Korean, Simplified Chinese, Traditional Chinese, or Japanese.
- Configure language, startup, desktop behavior, name indicators, and shortcuts
  from a unified settings window.
- Start automatically at Windows sign-in and restore hidden windows when exiting,
  with a separate recovery process for unexpected termination.

## Download and run

Requires **Windows 11 x64**. The release ZIP includes the .NET 10 runtime; you do
not need to install the .NET SDK or runtime separately.

1. Download `DisplaySpaces-1.0.0-win-x64.zip` from the
   [v1.0.0 release](https://github.com/ctenhank/DisplaySpaces/releases/tag/v1.0.0).
2. Extract the entire ZIP into a folder. Keep the executable and all supporting
   files together.
3. Run `DisplaySpaces.exe`.

For a stable installation, first exit any running copy through
**Exit · Restore all windows** in its tray menu. Then open PowerShell in the
extracted folder and run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -PublishDirectory . -Launch
```

This installs the app in `%LOCALAPPDATA%\Programs\DisplaySpaces` and starts
it in the background. Use this same installation location for future updates to
avoid duplicate entries in Windows system tray history. Exit the app before
updating it. The execution-policy option applies only to this PowerShell process.

If automatic startup was enabled from another folder, enable **Start with Windows**
again under **Settings → General** in the installed app to update the executable
path. Existing preferences are preserved.

**Upgrading from BetterVirtualDesktop:** Exit the old app through
**Exit · Restore all windows**, then install and launch DisplaySpaces using the
command above. If you use automatic startup, enable **Start with Windows** again
under **Settings → General** in DisplaySpaces to register the new executable
location. Preferences are read from the existing
`%LOCALAPPDATA%\IndependentVirtualDesktop` folder automatically.

The release also includes `SHA256SUMS.txt`. To verify the downloaded ZIP, compare
its listed hash with:

```powershell
Get-FileHash .\DisplaySpaces-1.0.0-win-x64.zip -Algorithm SHA256
```

## Default shortcuts

| Action | Shortcut |
| --- | --- |
| Open or close task view on all displays | `Win + Alt + Tab` |
| Previous or next desktop, anchored to the display under the pointer | `Win + Ctrl + Left / Right` |
| Create and switch to a desktop | `Win + Ctrl + D` |
| Remove the current desktop | `Win + Ctrl + F4` |
| Move the active window to the previous or next desktop | `Win + Ctrl + Shift + Left / Right` |
| Restore all windows and pause | `Win + Ctrl + Shift + F12` |

In task view, use the arrow keys to preview desktops, `Enter` to switch, and `Esc`
to close. `Win + Tab` opens Windows task view by default; open **Settings… → Shortcuts
→ Keyboard shortcuts…**, select the **Windows shortcuts** preset, and save to use
it for DisplaySpaces.

## Settings

Right-click the system tray icon and choose **Settings…**. Use **General** for
language and startup, **Desktops** for switching and window movement,
**Appearance** for desktop name indicators, and **Shortcuts** to open the shortcut
editor.

Settings changes are saved and applied immediately. The shortcut editor has
separate **Save changes** and **Cancel** actions. DisplaySpaces shortcuts and
taskbar desktop switching pause while Settings is open; close Settings to use them
again. Desktop name indicators are also hidden while Settings is open.

## Behavior and limitations

- These are app-managed workspaces. They are separate from Windows' built-in
  virtual desktops.
- Desktop names, order, and window assignments last for the current app session.
  Language, shortcuts, startup, and display/navigation preferences are saved.
- Moving a window by drag-and-drop or a destination menu keeps the current desktop
  open. The optional follow setting applies to previous/next window-move shortcuts.
- Some elevated, protected, or special-purpose windows may not be manageable.
  Hidden-window previews can show a cached image or icon depending on the app.
- Use the tray exit command to restore managed windows before closing or updating.
